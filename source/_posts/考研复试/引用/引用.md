 #### 引用作为函数返回值

  1. 不要返回局部变量的引用
  2. 函数的调用可以作为左值（静态变量，存放在全局变量）
  ```c++

int& test02(){
   static int a = 10;
   return a; //返回a的引用
}
  int &ref = test02();
  cout << ref <<endl;//10
  test02() = 1000;
  cout << ref << endl;//1000 
```

#### 引用的本质

本质：就是一个指针产量（指针不可以改变，指针的值可以改变）
