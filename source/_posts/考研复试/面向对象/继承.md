
#### 使用方法

```c++
class inheritance:public baseClass
```

#### 继承方式

共有继承
保护继承
私有继承

共有：
私有不可访问
其他在父类的权限属性不变
保护：
私有不可访问
共有变成保护，保护不变
私有：
子类继承下来的成员属性全部变成私有，但是父类的私有依然不可访问


#### 继承模型

非静态属性都会被子类继承
私有属性也被继承了，只不过被隐藏了

#### 继承中构造和析构的顺序

子类继承父类后
先创造父亲再继承儿子
儿子最新销毁，父亲最后销毁

#### 继承同名怎么办

```c++
	out << i.age << " " << i.name << endl;

    cout << i.inheritance::age << " " << i.inheritance::name << endl;
```

子类访问父类要通过作用域

调用函数同理
如果子类出现和父类同名的函数，子类会隐藏父类所有的同名函数，包括重载函数


#### 静态成员同名的方法
1.通过对象访问
直接访问是子类
加作用域是父类的
2. 通过类名访问
``` c++
son::m_a
son::base::m_a
```


同名方法
和成员一致
子类有同名函数会把父类的隐藏

#### 多继承语法

```c++
class 子类： 继承方式 父类1，继承方式 父类2
```

不太建议使用

对于有二义性的的，比如父类里面有重名函数那么应该加上作用域

#### 菱形继承，虚基类的定义与使用

两个派生类继承同一个基类

又有某个类同时继承这两个派生类
这种继承被称为菱形继承

对动物的成员属性无法区分

加上virtual变成虚继承 class sheep : virtual public animal{} 最大的类animal
