#### 访问权限

三种权限
public：都能访问
protected：类内可以访问，儿子可以访问
private：类内可以访问，儿子不可以访问

**struct与class的区别** 
区别在于访问权限的不同，struct的访问权限为公共，class的默认权限为私有


对成员变量使用private，使用public 来做get，set方法


#### 构造函数，初始化

构造函数：主要创建对象时为成员属性初始化，编译器自动调用
析构函数：对象销毁前自动调用，执行清理工作

**构造函数**  
1. 构造函数，返回值void
2. 函数名称与类名相同`类名(){}`
3. 构造函数可以有参数，发生重载
4. 程序在调用对象会自动调用构造，只调用一次

**析构函数**

1. 返回值void
2. `~类名(){}`
3. 不能有参数，不能重载
4. 自动调用，只调用一次

#### 深拷贝浅拷贝

析构函数一般在释放对象的时候释放堆区的资源
浅拷贝：不生成新的地址，只拷贝值
深拷贝：生成新的内存
浅拷贝会导致内存被重复删除
``` c++
~Person(){//析构函数
	if(height!=null){
	delete height;
	heght = null;
	}//height为成员对象，由于height的内存是指向一块的，因此就会导致重复内存删除，导致报错
}

Person p1(18);
Person p2(p1);
//报错
```
深拷贝
```c++
Person(const Person &p){
	m_height = new int(*p.m_height);//p.m_height在堆内存中，此时是要用指针取出其中的值
}
```

如果有成员变量是开辟堆的内存来设置的，一定要深拷贝

#### 静态成员


静态成员变量
1. 所有对象共享同一份数据，其他对象改数据，则其他对象所对应的静态成员也会改变
2. 在编译阶段分配内存，在全局区
3. 类内声明，类外初始化

```c++
class Person {


	public:
		static int age;

};

int Person::age = 10;

int main() {

	Person p;
	cout << p.age << endl;
	Person p2;
	p2.age = 200;//共享同一个变量
	cout << p.age<<endl;
	//由于在编译阶段就分配了内存，因此不属于任何对象，可以直接访问
	cout << Person::age<<endl;

}
```

静态成员函数
1. 所有对象共享同一个函数
2. 静态成员函数只能访问静态成员变量
``` c++
class Person {
	public:
		static int age;
		static void funcUtil(){
			cout<<"我这个就是一个烂裤裆"<<endl;
			cout<<age<<endl;
		}
};

int Person::age = 10;

int main() {


	Person::funcUtil();
}

```
由于非静态成员变量是随着对象出现而出现，因此，静态方法是不能调用非静态成员变量，函数体不需要创建对象，因此非静态成员变量会无法区分非静态变量到底属于哪个成员。



#### c++ 对象模型

类内的成员变量和成员函数分开存储
**只有非静态成员变量才属于类的对象上**

也就是说静态的成员变量或者函数不会导致对象的sizeof的值变化

非静态成员函数也不属于类的对象上

#### 常对象、常引用与常成员函数及其使用

 1. **常对象（const objects）**

**定义**：  
常对象是指被 `const` 修饰的对象，其所有数据成员在生命周期内不可修改。常对象只能调用常成员函数（const member functions），不能调用普通成员函数

```c++
const ClassName obj(params); // 或 ClassName const obj(params);
```
1. 必须初始化
2. 成员数据不可被修改，只能调用常成员函数

**常引用（const references）**
**定义**：  
用 `const` 修饰的引用，指向的对象不可通过该引用被修改。常引用常用于函数参数，避免意外修改实参

1. 保护数据
2. 避免对象拷贝（当函数的参数时候，会触发拷贝）

**常成员函数（const member functions）**
**定义**：  
在成员函数声明和定义末尾添加 `const` 关键字，表示该函数不会修改类的非静态成员变量（`mutable` 修饰的成员除外）

1. 普通对象既可调用普通的成员函数，也可以调用非常成员函数
2.  常对象函数只能调用常成员函数
3. 常成员函数与同名非常成员函数构成重载，编译器根据对象类型选择调用版本
```cpp
class MyClass { public: int getValue() const; // 声明 
}; 
int MyClass::getValue() const { ... } // 定义
```
#### **常数据成员（const data members）**

**定义**：  
在类中声明为 `const` 的数据成员，需通过构造函数初始化列表初始化，且后续不可修改。
```cpp
class MyClass { public: MyClass(int x) : constMember(x) {} // 初始化列表 
private: const int constMember; 
};
```

类
