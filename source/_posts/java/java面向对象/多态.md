#### 什么是多态

- 同类型表示出不同的形态

- 如果没有方法重写，那么就不知道方法的调用是父类还是子类。

#### 调用成员的特点

- 调用成员变量是调用父亲的成员变量，编译也是编译父亲的成员变量

- 这是因为，变量是类型是父类，因此会去父类里面寻找成员变量并调用

- 而使用子类来创建对象的时候，因为类型是子类，因此寻找成员变量是在子类里面找

- 而调用方法的时候，则父亲有相同方法才能编译通过，但运行的时候是运行子类的成员方法（因为重写了）

#### 多态的优点

- 方便去耦合改写代码

- 可以用父类接受所有的子类。

#### 缺单

- 没法调用子类特有的方法。

- 解决办法：把子类转换成自己的类型，但是不能转换成其他类型。使用instance of来判断是否是那个子类。

- 没法调用子类自己的成员变量。
