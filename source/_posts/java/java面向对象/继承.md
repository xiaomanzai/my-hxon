- 继承
  
  就是当两个类有共性的时候，而又有不同的时候，可以通过继承调用相同的方法从而减少代码，和重用。

- 特点：java可以单继承，不能多继承，但支持多层继承。
  
  比如子类不可以有两个父类（多继承），但是子类可以有一个父类，而这个父类可以有父类。
  
  java所有的类都直接或者间接继承于object类。

- 子类能继承的内容
  
  构造方法：任何构造方法都不能被子类继承。（jvm无法分辨是构造那个类的实例）
  
  成员变量：任何成员变量都能被子类使用继承。
  
  成员方法：非私有可以，私有不可以。

**成员变量可以被子类使用继承使用的原因：**

- 在创建对象的时候，在堆栈区会分成两部分一部分放父类的成员变量和自己的成员变量d当赋值的时候将会先寻找自己的变量，再找父亲的变量

#### 继承的调用方法和规则

##### 成员变量的调用方法

- 如果没有this，super的关键字按照就近原则进行调用

- this就是先查找调用本类的成员变量，如果本类没有则去父类找，而不是调用方法变量

- 在子类中不能写两个super调用，只能写一个super

##### 方法重写

- 添加@Override来告诉虚拟机重写方法

- Override可以检测代码

- 当重写后会对虚方法表进行重写。

重写规则

- 重写名称，列表 必须和父类中的一致

- 子类重写父类方法的时候，权限必须大于等于父类

- 返回值类型子类必须小于等于父类（子类的返回类毕竟不能超过父类的返回值）

- 重写建议和父类保存一致

- 只有保存到虚方法表中的方法可以被重写
