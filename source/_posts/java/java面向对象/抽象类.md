#### 抽象类

- 父类只能确定大概的方法，也就是确定方法因此是抽象的

- 而子类的方法一般都和父类不一样

- 抽象类的父类子类的方法必须重写 

- 抽象类是在修饰符后加入abstract

#### 抽象方法

- 抽象方法添加public后不需要添加{}

#### 抽象类和抽象方法的特点

- 抽象类不能实例化（因为抽象类中没有执行的句子，实例化完全没有意义）

- 抽象类可以没有抽象方法，但是有抽象方法一定是抽象类

- 可以有构造方法（这是给子类赋值的  ）

- 抽象类的子类
1. 抽象子类的方法必须要重写（一般都是这种）

2. 子类是抽象类

#### 抽象类的意义

可以强制别人在子类中按照父类的方法格式来写（统一格式）
