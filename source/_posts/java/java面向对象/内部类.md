#### 匿名内部类

![](C:\Users\seasyec\AppData\Roaming\marktext\images\2023-03-13-23-08-55-image.png)

指的是直接创建的类，没有类名。直接创建类或者接口，抽象类的实现类

没有名字的类是括号区域，包括new 则是对象的概念

匿名内部类会在本地自动生成文件

**用途**

使用匿名内部类可以不用创建JavaBean子类而直接给方法传递类变量

可以不写实现类直接写![](C:\Users\seasyec\AppData\Roaming\marktext\images\2023-03-13-23-34-51-image.png)

如果不用匿名内部类则需要要用写实现类重写方法，再使用接口多态来解决
