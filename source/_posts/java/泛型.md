泛型是 jdk 5的特性指的是在编译阶段约束操作的数据类型，并进行检查

格式：<数据类型>

只能支持引用数据类型

好处：统一数据类型，编译的时候就定义了能存储的数据

伪泛型 ： 集合依然会把数据当作 object 来处理，在底层自动进行强转
			class 类型中的的泛型被编译清楚泛型的擦除
